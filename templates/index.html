📄 Import shipments from a manifest
Upload a cargo manifest as a PDF, Excel (.xlsx), CSV or Word (.docx) file to pull in multiple shipments at once. For Excel, CSV and Word files you'll first match the file's columns to the system's fields. You'll then get a chance to review and edit everything before it's saved — nothing is added automatically.
💾 Download a backup
Downloads a single .zip with all your current data — shipments, flights, recycle bin, users, and the activity log.
♻ Restore from a backup
Uploading a backup replaces your current data with what's in that file. A safety copy of your current data is taken automatically first, so this can be undone if something goes wrong — contact whoever manages your server if you ever need that safety copy restored.
